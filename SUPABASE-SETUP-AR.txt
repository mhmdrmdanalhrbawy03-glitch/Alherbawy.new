إعداد قاعدة بيانات مؤسسة الحرباوي على Supabase

1) افتح https://supabase.com وأنشئ مشروعًا جديدًا.
2) من Project Settings > API انسخ Project URL و anon/public key.
3) افتح supabase-config.js وضع القيم مكان YOUR-PROJECT و YOUR_SUPABASE_ANON_KEY. استخدم anon key فقط.
4) من SQL Editor في لوحة Supabase افتح ملف supabase-schema.sql والصق محتواه ثم اضغط Run.
5) من Authentication > Users أنشئ مستخدمًا للإدارة ببريد إلكتروني وكلمة مرور قوية.
6) انسخ UUID الخاص بالمستخدم من قائمة Users. في SQL Editor نفّذ: insert into public.profiles(id, role) values ('UUID-HERE','admin'); واستبدل UUID-HERE بالمعرف الحقيقي.
7) ارفع كل ملفات هذا المشروع إلى جذر مشروع Vercel. افتح /admin.html وسجّل الدخول بحساب الإدارة.

ما الذي يعمل بعد الربط؟
- المنتجات النشطة تُقرأ من قاعدة البيانات بدل القائمة الثابتة.
- طلبات الكتالوج تُحفظ في جدول orders ثم تُفتح رسالة واتساب.
- استفسارات صفحة التواصل تُحفظ في inquiries ثم تُفتح رسالة واتساب.
- لوحة /admin.html تتيح الدخول، إضافة وتعديل وحذف المنتجات، إخفاء المنتجات، متابعة الطلبات وتغيير حالتها، ومراجعة الاستفسارات.

الأمان: لا تضع service_role key في الموقع مطلقًا. ملف SQL يفعّل RLS ويمنع الزوار من قراءة طلبات واستفسارات العملاء. لا تمنح دور admin إلا لحسابك. لا تشارك كلمة مرور الإدارة.

ملاحظة: الأسعار اختيارية، وصور المنتجات تضاف كرابط صورة عام حاليًا. رفع الصور إلى Supabase Storage يمكن إضافته في مرحلة تالية.

تم إدخال Project URL ومفتاح Publishable المرسلَين في ملف supabase-config.js.
ما زال يلزم تشغيل ملف supabase-schema.sql داخل SQL Editor في مشروع Supabase، ثم إنشاء مستخدم Admin وإضافة دوره كما هو موضح أعلاه. لا تعتبر قاعدة البيانات مفعلة بالكامل قبل تنفيذ هذه الخطوات.
